Synology Disk Stations (DS) can be vulnerable if not properly configured:\

1. **Web interface**: Always use the latest version and enable CSRF protection.
2. **Services**: Disable unnecessary services (SSH, Rsync, etc.) and set strong passwords.
3. **Volume permissions**: Make sure volumes are read/writeable by root only.
4. **SMB vulnerabilities**: Enable SMBv2 support if possible to avoid EoP attacks.
5. **Common exploitable points**:
   - Web applications on the DS
   - SSH access without strong authentication
   - Unpatched services (PHP, etc.)
6. **Useful commands**:
   ```
   # Check version info
   synoinfo
   # Enumerate services
   ls -la | grep .service -type f 2>/dev/null
   # List installed packages
   pkg list -f
   ```

Always back up before making changes and test them in a controlled environment.
